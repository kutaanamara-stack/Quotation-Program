# 餐具修复报价工具使用说明

## 推荐入口

电脑端请双击：
`start-webapp.cmd`

手机端优先打开公网分享入口：
`https://kutaanamara-stack.github.io/Quotation-Program/mobile.html`

如果对方手机打不开上面的 GitHub Pages 链接，请改发备用 CDN 单文件链接：
`https://cdn.jsdelivr.net/gh/kutaanamara-stack/Quotation-Program@main/mobile-offline.html`

如果备用 CDN 也打不开，请直接把本文件夹里的 `手机离线版.html` 发给对方。这个文件不依赖网络，手机收到后用浏览器打开即可使用。

## 重要说明

不要直接双击 `webapp/index.html` 或 `网页版/index.html`。这类网页需要通过本地小服务或公网链接打开，直接双击文件时，部分浏览器会显示空白页。

如果手机在微信里点开失败，请点右上角，选择“在浏览器打开”。如果手机浏览器仍打不开，请把手机型号、运营商和错误截图发给管理员。

## 电脑端使用步骤

1. 双击 `start-webapp.cmd`
2. 等浏览器自动打开报价工具
3. 使用期间保持启动窗口打开
4. 用完后关闭启动窗口即可

如果电脑提示没有 Python，请改用手机公网链接，或联系管理员安装 Python 3。

## 手机端使用步骤

优先在手机浏览器打开：
`https://kutaanamara-stack.github.io/Quotation-Program/mobile.html`

如果打不开，再打开备用 CDN 单文件链接：
`https://cdn.jsdelivr.net/gh/kutaanamara-stack/Quotation-Program@main/mobile-offline.html`

如果两个链接都打不开，请让管理员把 `手机离线版.html` 作为文件发给手机。

## 报价操作

1. 输入客户公司名称
2. 填写固定规格对应的数量
3. 需要统一调价时打开“高级设置”，修改统一系数
4. 某一行需要单独改价时，在“高级设置”里启用该行手动单价
5. 检查预览和合计
6. 点击“导出图片”或“导出 PDF”

## 常见问题

如果电脑端打开空白页，请确认是双击了 `start-webapp.cmd`，不要直接打开 `webapp/index.html`。

如果手机公网链接打不开，先尝试复制链接到手机自带浏览器、Safari 或 Chrome 打开；如果仍打不开，请使用备用 CDN 链接或手机离线版文件。
